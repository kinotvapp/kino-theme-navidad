# Navidad

Verde de abeto, rojo de bola y dorado de estrella: la Navidad en toda la app.

Tema para [Kino](https://github.com/kinotvapp/kino-light). Cambia los colores, el fondo, las formas y el logo de toda la app, trae una pantalla de presentación y no se conecta a internet.

En Kino, escribe `kinotvapp/kino-theme-navidad` en **Plugins ▸ Agregar un plugin**. Después ábrelo y pulsa **Activar**.

Cuesta 10 kinos, la moneda gratuita de Kino: se compra una vez y vale en todos tus aparatos.

Necesita Kino 0.9.81 o superior.
